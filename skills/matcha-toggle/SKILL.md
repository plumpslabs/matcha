# /matcha-toggle · Toggle matcha on/off

Run `matcha toggle` in the terminal to flip the current matcha state.

- If matcha is **ON** → turns **OFF** (all hooks silenced, zero overhead)
- If matcha is **OFF** → turns **ON** (all hooks re-activated)

**Usage:** type `/matcha-toggle` or run `matcha toggle` in terminal.
